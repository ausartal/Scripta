# Scripta website

Mode: Persuade, with portfolio exploration.

## Direction contract
THESIS: Bring the supplied illustrated creative studio into a responsive, working website.
OWN-WORLD: Figma's warm off-white #f0ede4, charcoal #212529, deep ink #1a1d21, purple #8338ec, orange #fb5607, and peach #ffd5bd. Anton display and Inter body; original anime illustration assets, rounded panels, deliberate overlapping hero composition.
STORY: Understand the studio, explore services and honest concept work, compare scope-based packages, prepare a project brief.
FIRST VIEWPORT: Original logo in a 72px navigation strip; large left-aligned Anton headline beside the original illustrated character on a purple sweep. Project and portfolio actions remain clear. Mobile stacks the headline, original mobile artwork, then description/actions.
FORM: User-pinned Figma desktop, tablet, and mobile compositions. No alternate visual-world selection is required. Extend this established supplied world to pricing and existing routes.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## UX decisions
Five primary navigation destinations plus project CTA, with FAQ/process in footer and contextual links. Portfolio filter and pagination live in URL parameters; categories reset page. Three pricing choices reduce comparison burden; scope and deliverables precede quote action. Route changes restore top and focus; query changes preserve page context. Contact prepares a downloadable brief until a delivery service is configured.
